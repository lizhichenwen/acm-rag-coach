题目：两数之和
难度：简单
标签：哈希表,数组
描述：给定一个整数数组 nums 和一个目标值 target，请在数组中找出和为目标值的两个整数，返回它们的下标。假设每种输入只对应一个答案，同一元素不能重复使用。
题解思路：用哈希表记录"数值 → 下标"。遍历数组，对每个元素 x，先查哈希表中是否存在 target - x：存在就返回两个下标；不存在就把 x 和它的下标存进哈希表。时间复杂度 O(n)，空间 O(n)。
常见错误：直接写双重循环，O(n²) 导致 TLE；或者先把所有元素放进哈希表再查，导致同一个元素被用两次。

题目：三数之和
难度：中等
标签：双指针,排序,数组
描述：给定一个整数数组，找出所有和为 0 且不重复的三元组。
题解思路：先排序；固定第一个数 nums[i]，在它右边的区间用左右双指针找两数之和为 -nums[i]。移动指针时跳过重复元素，保证三元组不重复。复杂度 O(n²)。
常见错误：不去重导致输出重复三元组；直接三重循环 O(n³) 超时；双指针移动条件写反。

题目：最长回文子串
难度：中等
标签：字符串,动态规划,中心扩展
描述：给定一个字符串 s，找到 s 中最长的回文子串。
题解思路：中心扩展法。枚举每个字符作为奇数长度的中心、每对相邻字符之间的空隙作为偶数长度的中心，向两边扩展并比较字符，记录最长区间。O(n²) 时间、O(1) 空间。也可用区间 DP。
常见错误：只考虑奇数长度中心，漏掉偶数长度回文（如 "abba"）；暴力枚举所有子串 O(n³) 超时。

题目：接雨水
难度：困难
标签：双指针,单调栈
描述：给定 n 个非负整数表示柱子的高度，计算这些柱子下雨后能接多少雨水。
题解思路：双指针。维护 left_max 与 right_max，每次移动较矮的一侧，该位置能接的水为 min(left_max, right_max) - height[i]，累加即可。O(n) 时间、O(1) 空间。
常见错误：只按单侧最大值计算；对每个位置向两边扫描最大值，O(n²) 超时。

题目：零钱兑换
难度：中等
标签：动态规划,完全背包
描述：给定不同面额的硬币和总金额 amount，求凑成该金额所需的最少硬币数，凑不出返回 -1。
题解思路：完全背包。dp[j] 表示凑出金额 j 的最少硬币数，dp[0]=0，其余初始化为无穷大；外层枚举硬币，内层对金额正序遍历，dp[j]=min(dp[j], dp[j-coin]+1)。
常见错误：把完全背包写成 0/1 背包（金额倒序），导致每种硬币只能用一次；初始值没设成无穷大导致结果错误。

题目：01背包
难度：中等
标签：动态规划,背包
描述：有 n 件物品，每件有重量 w 和价值 v，背包容量为 W，每件物品最多选一次，求能获得的最大价值。
题解思路：dp[j] 表示容量为 j 时的最大价值。外层枚举物品，内层对容量倒序遍历，dp[j]=max(dp[j], dp[j-w]+v)。倒序是为了保证每件物品只被选一次。
常见错误：容量正序遍历，导致同一物品被重复使用，退化成完全背包。

题目：二分查找
难度：简单
标签：二分,查找
描述：在升序数组中查找目标值，返回其下标，不存在返回 -1。
题解思路：维护闭区间 [l, r]，取 mid=(l+r)//2；nums[mid]==target 时返回，否则根据大小收缩区间。
常见错误：while(l<r) 与 l=mid 混用导致死循环；边界写成 l=mid+1 但 r=mid-1 时又用 l<r，逻辑不一致；mid 用 (l+r)/2 在部分语言中溢出。

题目：搜索旋转排序数组
难度：中等
标签：二分,数组
描述：一个升序数组在某处旋转后，在其中查找目标值，返回下标或 -1。
题解思路：二分时先判断 mid 落在左半段还是右半段的有序区间，再判断 target 是否落在该有序区间内，据此决定收缩方向。O(log n)。
常见错误：只比较 nums[mid] 与 target，忽略旋转后"局部有序"的结构；边界判断漏掉等号。

题目：合并K个升序链表
难度：困难
标签：堆,分治,链表
描述：合并 k 个升序链表为一个升序链表。
题解思路：小根堆中存放每个链表当前的头节点，每次弹出最小节点接到结果链表，再把该节点的 next 压入堆。总复杂度 O(N log k)。也可用两两分治合并。
常见错误：每次遍历 k 个头节点找最小，O(Nk) 超时；递归合并过深导致栈溢出。

题目：岛屿数量

题目：滑动窗口最大值
难度：困难
标签：单调队列,滑动窗口
描述：给定数组和窗口大小 k，返回每个滑动窗口中的最大值。

常见错误：用普通队列每次遍历窗口求最大值，O(nk) 超时；忘记弹出过期下标。

题目：最长递增子序列
难度：中等

题解思路：O(n²) 做法：dp[i] 表示以 i 结尾的 LIS 长度，dp[i]=max(dp[j])+1（j<i 且 a[j]<a[i]）。更优做法是维护 tails 数组并用二分查找更新，O(n log n)。

题目：前缀和
难度：简单
标签：前缀和,数组
描述：给定数组，多次查询区间 [l, r] 的元素和。
题解思路：预处理 pre[i]=pre[i-1]+a[i]，则区间和 = pre[r]-pre[l-1]，单次查询 O(1)。建议使用 1-based 下标避免边界讨论。
常见错误：下标偏移导致越界；区间端点写错（写成 pre[r]-pre[l]）；没有处理 l=0 的情况。

题目：拓扑排序
难度：中等
标签：图论,拓扑排序
描述：给定一个有向图，输出任意一个拓扑序；若图中存在环则无解。
题解思路：统计每个点的入度，把入度为 0 的点入队；依次出队并删去它的出边，被删边的点入度减一，减到 0 时入队。若输出点数小于 n，说明有环。
常见错误：忘记检测环；更新入度时漏掉某些边；队列里重复入队同一个点。

题目：快速幂
难度：简单
标签：数论,位运算,二分
描述：给定 a、n 与模数 mod，求 a^n mod mod 的值，n 可达到 1e9。
题解思路：二分思想。把指数 n 按二进制拆分：res=1，base=a；当 n 为奇数时 res=res*base%mod；每次 base=base*base%mod，n>>=1。复杂度 O(log n)。
常见错误：循环条件写成 while(n>0) 却忘记 n>>=1 导致死循环；用 int 做乘法 a*a 时溢出，应先取模再乘；忘记处理 mod=1 的特殊情况。

题目：最大子数组和
难度：简单
标签：动态规划,分治
描述：给定一个整数数组，找出一个具有最大和的连续子数组，返回其最大和。
题解思路：动态规划：dp[i] 表示以 i 结尾的最大子段和，dp[i]=max(a[i], dp[i-1]+a[i])，答案为 max(dp)。也可用分治法在 O(n log n) 内求跨越中点的最大和。
常见错误：初始化 ans 为 0 而非负无穷，导致全负数数组得到 0；分治时跨中点合并的左右最大和边界算错。

题目：最长公共子序列
难度：中等
标签：动态规划,字符串
描述：给定两个字符串 text1、text2，返回它们的最长公共子序列长度（子序列不要求连续）。
题解思路：dp[i][j] 表示 text1 前 i 个字符与 text2 前 j 个字符的 LCS 长度。相等时 dp[i][j]=dp[i-1][j-1]+1，否则 dp[i][j]=max(dp[i-1][j], dp[i][j-1])。O(nm)。
常见错误：与"最长公共子串"混淆，子串要求连续而子序列不要求；状态转移在字符不相等时漏掉 max 分支。

题目：Dijkstra 最短路
难度：中等
标签：图论,最短路,堆
描述：给定带非负权有向图与起点，求起点到所有点的最短距离。
题解思路：小根堆维护 (距离, 节点)，每次取出距离最小的节点，用它的出边松弛邻居；每个节点只在首次被取出时确定最短路。复杂度 O((V+E) log V)。
常见错误：在存在负权边时使用 Dijkstra（会出错）；堆里重复入队相同节点却忘记"已确定"标记；邻接表存边时方向写反。

题目：Kruskal 最小生成树
难度：中等
标签：图论,并查集,贪心
描述：给定带权无向连通图，求一棵权值和最小的生成树。
题解思路：按边权从小到大排序，依次考察每条边：若其两端不在同一并查集集合则加入生成树并合并。边数达到 n-1 时结束。复杂度 O(E log E)。
常见错误：边排序后未用并查集判环，导致成环；并查集忘记路径压缩使查找退化；忽略图不连通时无法生成整棵 MST。

题目：区间调度（活动选择）
难度：简单
标签：贪心
描述：给定若干区间 [start, end]，求最多能选出多少个互不重叠的区间。

题目：二分答案（最小化最大值）

题目：单调栈（下一个更大元素）
难度：中等
标签：单调栈,栈
描述：给定数组，对每个元素求"右侧第一个比它大的元素"，不存在则输出 -1。
题解思路：维护一个存下标的单调递减栈。从左到右遍历，当前元素比栈顶大时，栈顶的"下一个更大元素"就是当前元素，弹出并记录；最后把当前下标入栈。O(n)。

题目：一维差分
难度：简单
标签：差分,数组
描述：给定数组，进行多次"对区间 [l, r] 每个元素加 v"的操作，最后求数组。
题解思路：差分。构造差分数组 d[i]=a[i]-a[i-1]，区间加 v 等价于 d[l]+=v、d[r+1]-=v；最后前缀和还原。单次修改 O(1)，总复杂度 O(n+m)。
常见错误：还原时忘记从前往后做前缀和；区间右端点 r+1 越界未处理；把差分当成了前缀和来用。

题目：KMP 字符串匹配

题目：最大公约数（辗转相除）
难度：简单
标签：数论,递归
描述：给定两个正整数 a、b，求它们的最大公约数 gcd(a, b)。
题解思路：辗转相除法（欧几里得算法）：gcd(a, b) = gcd(b, a mod b)，当 b 为 0 时 a 即为答案。可递归也可迭代实现，复杂度 O(log min(a,b))。
常见错误：没有处理 a < b 的初始情况（其实第一次迭代会自动交换，但手写时容易误判）；对 0 取模导致 RE；写成 a % b 后忘记交换参数顺序。

题目：扩展欧几里得
难度：中等
标签：数论,递归
描述：给定整数 a、b，求整数 x、y 使得 ax + by = gcd(a, b)，并返回 gcd。
题解思路：在递归求 gcd 的同时回溯求解：边界时 x=1、y=0；回溯时由 bx' + (a mod b)y' = gcd 推出 x = y'，y = x' - (a/b)y'。可进一步用于求逆元和解线性同余方程。
常见错误：回溯时的系数更新公式写反；求出的解忘记约分；用它解 x ≡ c (mod m) 时忘记判断 gcd(a,m) 不整除 c 的无解情况。

题目：埃氏筛与欧拉筛
难度：简单
标签：数论,素数
描述：求 [2, n] 内所有质数，n 可达 1e7。
题解思路：埃氏筛：从 2 开始把每个质数的倍数标记为合数，复杂度 O(n log log n)。欧拉筛（线性筛）：让每个合数只被其最小质因子筛一次，复杂度 O(n)。1e7 以上建议用欧拉筛。
常见错误：从 i*i 开始筛时 i*i 溢出 int；把 1 当质数；埃氏筛对大 n 用 bool 数组而非 bitset 导致内存超限；线性筛中 break 条件写错导致重复筛。

题目：乘法逆元（费马小定理）
难度：中等
标签：数论,快速幂,模运算
描述：给定质数 p 和整数 a（p 不整除 a），求 a 在模 p 意义下的乘法逆元，即 ax ≡ 1 (mod p) 的 x。
题解思路：由费马小定理 a^(p-1) ≡ 1 (mod p)，得 a^(p-2) 即为逆元，用快速幂 O(log p) 计算。模数不是质数时需用扩展欧几里得求逆元。
常见错误：p 不是质数却直接套费马小定理；忘记判断 gcd(a,p)≠1 时逆元不存在；组合数取模时除法直接除而没有乘逆元。

题目：质因数分解
难度：简单
标签：数论,素数
描述：给定正整数 n（n ≤ 1e12），分解为质因数乘积并输出每个质因子及次数。
题解思路：试除法：从 2 到 sqrt(n) 枚举，能整除就不断除并计数；枚举完后剩余大于 1 的部分本身是质数。复杂度 O(sqrt(n))。n 更大时先筛出 sqrt(n) 内质数再试除质数。
常见错误：枚举到 n 而非 sqrt(n) 导致 TLE；忘记处理最后的剩余大质因子；把 i 是合数的情况也当质因子计数。

题目：组合数取模
难度：中等
标签：数论,组合数学,动态规划
描述：给定 n、m 和质数 p，求 C(n, m) mod p。
题解思路：n 较小时用杨辉三角递推 C(n,m)=C(n-1,m-1)+C(n-1,m)（可滚存）。n 大（1e5 级）且 p 为质数时，预处理阶乘与其逆元：C(n,m)=fact[n]*inv(fact[m])*inv(fact[n-m]) mod p。
常见错误：递推时数组大小不够；用逆元法时 p 不是质数或 p 小于 n 导致阶乘逆元无意义；费马小定理指数写成 p-1 而非 p-2。

题目：矩阵快速幂
难度：困难
标签：数论,矩阵,快速幂
描述：给定方阵 A 和指数 n（n 可达 1e18），求 A^n mod p。
题解思路：与快速幂同构：把"数乘"换成"矩阵乘"，n 按二进制拆分，res 初始化为单位矩阵。常用于递推数列（如斐波那契第 1e18 项）：把递推关系写成矩阵形式，复杂度 O(k³ log n)。
常见错误：res 初始化成全 1 而非单位矩阵；矩阵乘的三重循环顺序写错导致累加错位；递推矩阵的构造推错（状态向量顺序与转移矩阵不匹配）。

题目：Bellman-Ford 与判负环
难度：中等
标签：图论,最短路
描述：给定可能含负权边的图与起点，求单源最短路；若存在负环需要报告。
题解思路：对每条边做 n-1 轮松弛，第 i 轮结束后得到"至多经过 i 条边"的最短路。若第 n 轮仍能松弛，说明存在负环。复杂度 O(nm)。队列优化版本为 SPFA。
常见错误：只做了一轮松弛就输出；用 Dijkstra 处理负权边；SPFA 判负环时用"入队次数 ≥ n"而非"松弛轮数 ≥ n"。

题目：Floyd 全源最短路
难度：中等
标签：图论,最短路,动态规划
描述：给定 n（n ≤ 500）个点的带权图，求所有点对之间的最短路径。
题解思路：三重循环，外层必须是中转点 k：dis[i][j] = min(dis[i][j], dis[i][k] + dis[k][j])。本质是 DP：dp[k][i][j] 表示只允许经过前 k 个点作中转的最短路。复杂度 O(n³)。
常见错误：把中转点 k 放在最内层循环（结果错误）；初始化 dis[i][i]=0、其余无穷大时无穷大相加溢出；忘记处理重边取最小。

题目：Prim 最小生成树
难度：中等
标签：图论,最小生成树,堆
描述：给定带权无向连通图，用 Prim 算法求最小生成树的边权和。
题解思路：从任意点出发，维护"已生成树到每个未加入点的最小边权"，每轮用堆取出最小者并将其加入生成树，同时用新点的出边更新其他点的最小边权。堆优化后复杂度 O(E log V)，适合稠密图可用朴素 O(V²) 版。
常见错误：加入生成树后忘记更新邻接点的候选边权；堆里存的是已加入的点；图不连通时没有判无解。

题目：树的直径（两次 BFS）
难度：中等
标签：图论,树,BFS
描述：给定一棵树，求树上距离最远的两个节点之间的路径长度（边数或边权和）。
题解思路：从任意点 u 做 BFS/DFS 找到距 u 最远的点 s；再从 s 出发找到距 s 最远的点 t，则 s 到 t 的路径即为直径。两次搜索 O(n)。也可用树形 DP：每个点维护向下的最长链与次长链。
常见错误：带边权的树用 BFS 层数当距离；两次 BFS 的起点记录错；树形 DP 中最长链+次长链经过同一点导致路径非法。

题目：最近公共祖先（倍增 LCA）
难度：困难
标签：图论,树,倍增
描述：给定一棵根树，多次查询点 u、v 的最近公共祖先。
题解思路：预处理每个点向上跳 2^j 步到达的祖先 fa[j][u]（倍增表）。查询时先把深度大的点跳到与另一个同深度，再两个点同时向上跳到 LCA 的孩子，最后返回其父亲。预处理 O(n log n)，单次查询 O(log n)。
常见错误：深度没有先对齐就同时上跳；fa 表初始化根的父亲为 0 但查询时没有排除；DFS 递归过深（大树上改用 BFS 预处理）。

题目：二分图判定（染色法）
难度：简单
标签：图论,二分图,DFS
描述：给定无向图，判断它是否是二分图（能否把点集分成两部分，使所有边的两端点分属不同部分）。
题解思路：对每个连通分量做 DFS/BFS 染色，相邻点必须异色；若发现相邻两点同色则不是二分图。无奇环的图等价于二分图。复杂度 O(n+m)。
常见错误：图不连通时只从一个点开始染色；用邻接矩阵存稀疏图超内存；判断奇环时只检查环长忘了自环。

题目：匈牙利算法（二分图匹配）
难度：困难
标签：图论,二分图,匹配
描述：给定二分图，求最大匹配数（最多的边，使得每个点至多连一条边）。
题解思路：对左部每个点尝试增广：DFS 寻找一条"交替路"，若终点是未匹配的右部点则匹配数+1，期间允许"抢"已匹配点重新安排。复杂度 O(V·E)。也可用 Dinic 最大流实现更快。
常见错误：忘记 vis 数组导致增广路成环死循环；增广失败后没有回溯状态；左右部点数用混。

题目：线段树（区间求和）
难度：困难
标签：数据结构,线段树,分治
描述：给定数组和两种操作：单点修改值；查询区间 [l, r] 的和。操作数可达 2e5。
题解思路：线段树把区间二分建树，每个节点维护对应区间的和。修改时只更新根到该叶子路径上的节点（O(log n)）；查询时把 [l,r] 拆成 O(log n) 个不相交节点求和。带懒标记可实现区间修改。
常见错误：pushdown 忘记调用或标记下传后不清零；递归边界 l==r 与 r-l+1==1 混用；数组只开 4 倍空间不够；build 时左右子区间交界处下标算错。

题目：树状数组
难度：中等
标签：数据结构,树状数组,前缀和
描述：给定数组，支持单点加值与前缀和查询，操作数可达 2e5。
题解思路：树状数组（BIT）用 lowbit(x)=x&(-x) 划分子区间，c[i] 维护 (i-lowbit(i), i] 的和。查询前缀和：沿 i -= lowbit(i) 累加；单点修改：沿 i += lowbit(i) 向上更新。两者均 O(log n)，代码量远小于线段树。
常见错误：lowbit 写成 x & (x-1)（这是清零最低位）；下标从 0 开始导致 lowbit(0)=0 死循环；区间求和写成 sum(r)-sum(l) 少减了一位。

题目：ST 表（稀疏表）
难度：中等
标签：数据结构,ST表,倍增
描述：给定静态数组，多次查询区间 [l, r] 的最大值，不支持修改。
题解思路：预处理 st[j][i] 表示从 i 开始长度 2^j 的区间最大值，递推 st[j][i]=max(st[j-1][i], st[j-1][i+2^(j-1)])。查询拆成两段可重叠的长度 2^k 区间取 max，k=log2(r-l+1)。预处理 O(n log n)，查询 O(1)。注意只适用于可重复贡献的运算（max/min/gcd）。
常见错误：用 ST 表查询区间和（加法不满足可重复贡献，会重复计算）；log2 用浮点函数在边界处取整误差；预处理 j 的枚举上界算错。

题目：字典树（Trie）
难度：中等
标签：数据结构,字符串,树
描述：维护一个字符串集合，支持插入、查询某串是否存在，以及查询以某前缀开头的串的数量。
题解思路：Trie 每个节点有 26 个儿子指针（或数组），根到节点的路径拼出前缀。插入/查询沿字符逐层走，O(|s|)。可在节点上存 pass/end 计数支持前缀统计。
常见错误：忘记释放/复用节点导致多组数据内存爆炸（可用静态数组+下标复用）；儿子数组开小；查询时走到空节点没有及时返回。

题目：字符串哈希
难度：中等
标签：字符串,哈希
描述：给定文本串与模式串，多次判断文本的任意子串是否等于模式串或互相相等。
题解思路：把字符串映射为大整数（如把字符当 base 进制数模大质数）。预处理前缀哈希 h[i]，则子串 [l,r] 的哈希可 O(1) 计算：h[r]-h[l-1]*base^(r-l+1)。双哈希（两组 base 与模数）可把碰撞概率降到极低。
常见错误：单哈希被构造数据卡（自然溢出 unsigned long long 也可能被卡）；取模减法出现负数忘记加模；base 与模数共用导致退化。

题目：Manacher 最长回文
难度：困难
标签：字符串,回文
描述：给定字符串 s，求最长回文子串，要求 O(n) 或接近线性的算法。

常见错误：忘记插入分隔符导致偶回文处理错；p 数组含义（半径/直径）记混；开数组忘了首尾哨兵。

题目：归并排序求逆序对

描述：给定数组，求满足 i < j 且 a[i] > a[j] 的数对个数（逆序对数）。
题解思路：归并排序合并左右两半时，若右半元素先于左半元素放入，则左半剩余未放元素都与其构成逆序对，统计 mid-i+1。总复杂度 O(n log n)。也可用树状数组离散化统计。

题目：离散化

描述：值域很大（如 1e9）但个数不多（1e5）时，把原值映射为 1..m 的紧凑下标，配合树状数组/线段树做统计。

题目：记忆化搜索
难度：中等
标签：搜索,动态规划,递归
描述：给定二维网格，每步可走向数值更大的相邻格，求最长滑行长度。状态依赖无法简单顺序枚举。

题目：八数码 A* 搜索
难度：困难

描述：3×3 棋盘上 8 个数字与一个空格，每步移动空格，求从初始局面到目标局面的最少步数。

题目：跳跃游戏（贪心可达性）
难度：中等
标签：贪心,数组
描述：数组第 i 个元素表示从 i 最多能向前跳多少步，判断是否能从下标 0 跳到最后一格。
题解思路：贪心维护当前能到达的最远位置 farthest：遍历每个下标 i，若 i > farthest 说明不可达直接返回 false；否则更新 farthest = max(farthest, i + nums[i])。能遍历到 n-1 即可达。O(n)。
常见错误：在 i > farthest 时没有提前退出还继续更新；把"每步必须跳 nums[i] 步"与"最多跳 nums[i] 步"混淆；用 DP 从后往前反而写错边界。

题目：合并果子（堆贪心）
难度：中等
标签：贪心,堆,优先队列
描述：n 堆果子，每次把两堆合并成一堆，代价为两堆数量之和，求把所有果子合并成一堆的最小总代价。
题解思路：哈夫曼思想：每次都取当前最小的两堆合并，代价最小。用小根堆维护，每次弹出两个最小值合并，把结果 push 回堆，共合并 n-1 次。总复杂度 O(n log n)。
常见错误：每次用排序找最小两堆 O(n² log n) 超时；合并后的新堆忘记放回；只剩一堆时还继续循环弹出。

题目：排序不等式（最小代价配对）
难度：简单
标签：贪心,排序
描述：给定两组数，两两配对求乘积和最小（或最大）。

题目：位运算技巧（lowbit 与状态压缩）
难度：中等
标签：位运算,状压
描述：lowbit(x) 返回 x 二进制最低位的 1 所代表的值。它是树状数组与状态压缩 DP 的基础工具。
题解思路：lowbit(x) = x & (-x)。枚举二进制子集：sub = (sub-1) & s 可按递减顺序枚举 s 的所有子集。n ≤ 20 时可用二进制数表示集合状态，是状压 DP 与枚举子集搜索的标准工具。

题目：异或的性质与应用
难度：中等
标签：位运算,数论
描述：利用异或运算的自反性（a^a=0、a^0=a）与结合律解决"只出现一次的数""区间异或和"等问题。
题解思路：成对出现的数异或后抵消，全体异或即得到落单的数。区间异或和可用前缀异或数组 pre[i]=pre[i-1]^a[i] 快速回答。若干数异或的值 x，其最高位 1 可以从异或结果直接读出。

题目：悬线法（最大子矩形）
难度：困难
标签：动态规划,矩阵,单调栈
描述：01 矩阵中求全为 1 的最大子矩形面积。
题解思路：对每个点维护悬线：up[i][j] 为向上最大全 1 高度，left/right 为该悬线能左右扩展到的边界（继承自上方行并与本行限制取交）。以 (i,j) 为底的最大矩形 = 高×(right-left+1)。O(nm)。等价于"对每行做直方图单调栈"。
常见错误：left/right 没有从上一行继承而是只看本行；边界初始化为 0 与 1 的含义混用；只维护高度没维护宽度。

题目：树形 DP（没有上司的舞会）
难度：中等
标签：动态规划,树,DFS
描述：公司人员构成一棵树（上下级），舞会不能同时邀请某人及其直接上司，求邀请名单的快乐值总和最大值。
题解思路：树上每个节点两个状态：dp[u][0] 表示 u 不来时子树最大值，dp[u][1] 表示 u 来。转移：dp[u][0]=Σmax(dp[v][0],dp[v][1])；dp[u][1]=a[u]+Σdp[v][0]。后序 DFS 合并。O(n)。
常见错误：把"不能相邻"理解成"父子不能同时在整棵树出现"；DFS 时用全局数组却多组数据没清空；转移时 u 来的情况误加了下属也来的值。

题目：区间 DP（石子合并）
难度：中等
标签：动态规划,区间
描述：n 堆石子排成一排，每次只能合并相邻两堆，代价为两堆之和，求最小总代价。
题解思路：区间 DP：dp[l][r] 表示合并 [l,r] 的最小代价，枚举分割点 k：dp[l][r]=min(dp[l][k]+dp[k+1][r])+sum(l,r)。按区间长度从小到大枚举。复杂度 O(n³)。前缀和预处理区间和。
常见错误：合并的"相邻"约束被忽略当成哈夫曼做；区间枚举顺序错（必须按长度）；sum 用循环每次重算导致 O(n⁴) 超时。

题目：状压 DP（旅行商问题）
难度：困难
标签：动态规划,状压,位运算
描述：n（n≤20）个城市两两之间有距离，求从 0 号城市出发每个城市恰经过一次再回到 0 的最短路径。
题解思路：状态压缩 DP：dp[S][i] 表示已访问集合为 S、当前在城市 i 的最小代价。转移枚举下一个城市 j：dp[S|1<<j][j] = min(dp[S][i]+dis[i][j])。答案为 min(dp[全集][i]+dis[i][0])。复杂度 O(2^n·n²)。
常见错误：状态定义漏掉"当前位置"；集合 S 用字符串而非二进制数导致无法枚举；n>20 时仍用状压指数爆炸；初始状态 dp[1][0]=0 写错。

题目：数位 DP（统计数字）
难度：困难
标签：动态规划,数位
描述：统计 [1, n] 中各位数字里出现 1 的总次数，n 可达 1e18。
题解思路：数位 DP：从高位到低位逐位确定，记忆化状态 (当前位, 是否贴上界, 前缀信息)。对每位分"该位取小于上界的数"与"贴上界"两种情况累加贡献。也可用按位组合数学公式直接算每个数位的贡献。复杂度与位数成正比。
常见错误：贴上界状态没有单独处理导致统计越界；前导零的处理遗漏；记忆化的数组只在"非贴上界"状态下有效这一前提忘记。

题目：斜率优化与单调队列优化 DP（概念）
难度：困难
标签：动态规划,单调队列,优化
描述：当 DP 转移形如 dp[i]=min{dp[j]+cost(j,i)} 且 cost 满足四边形不等式或可拆成关于 j 的线性函数时，可优化转移。
题解思路：单调队列优化：当 cost(j,i) 满足"决策点单调"时，用双端队列维护候选决策，队首即当前最优，均摊 O(1) 转移，总复杂度从 O(n²) 降到 O(n)。斜率优化把每个决策看成直线，用凸壳维护。判断依据：把转移方程移项后是否形如 y=kx+b。
常见错误：不验证决策单调性就直接套模板；队首弹出条件写反；斜率比较用除法有精度问题（改用叉积）。

题目：计算几何基础（叉积与方向）
难度：中等
标签：计算几何,向量
描述：给定三个点 A、B、P，判断 P 在有向线段 AB 的左侧、右侧还是共线；以及多边形面积计算。
题解思路：叉积 cross(B-A, P-A) > 0 表示 P 在左侧，< 0 在右侧，=0 共线。多边形面积按顶点顺序累加相邻边叉积再除 2（鞋带公式），结果取绝对值。叉积是几乎所有几何题的基础判断工具。
常见错误：顺时针/逆时针顶点顺序混淆导致符号相反；面积忘记除 2 或取绝对值；用浮点叉积判断共线有精度误差（改用整数坐标与符号判断）。

题目：凸包（Andrew 算法）
难度：困难
标签：计算几何,凸包,排序
描述：给定平面上 n 个点，求包围所有点的最小凸多边形（凸包）顶点序列。
题解思路：Andrew 单调链：按 x 再按 y 排序，分别构建下凸壳与上凸壳。入栈新点时，若栈顶两点与新点不满足"向左转"（叉积 ≤0）则弹出栈顶。两链拼接即为凸包。O(n log n)。
常见错误：排序比较器不严格（先 x 后 y）导致重复点；凸壳首尾点被重复加入；叉积 =0（共线）时是否保留点与题目要求不一致。

题目：表达式求值（中缀转后缀）
难度：中等
标签：栈,模拟,表达式
描述：给定含 + - * / 与括号的中缀表达式（无负数），求其值。
题解思路：双栈法：数字栈与运算符栈。扫描到数字入栈；运算符在入栈前把栈中优先级 ≥ 它的先弹出去计算；左括号直接入栈，右括号一路弹到左括号。最后清栈。也可先转后缀表达式再求值。
常见错误：乘除与加减优先级处理错；括号匹配没处理空括号；整数除法向零取整与题目要求的取整方向不一致。

题目：树的遍历（前中后序与层序）
难度：简单
标签：树,DFS,BFS,递归
描述：给定二叉树的前序与中序遍历序列，重建二叉树并输出后序遍历。
题解思路：前序第一个元素是根；在中序中定位根，把序列分成左子树与右子树两段，递归构建。后序=先递归左、再递归右、最后输出根。若给后序+中序同理（后序最后一个是根）。
常见错误：在中序中用值找根但树中有重复值（应改用哈希记录位置）；区间端点在递归两侧没有正确缩减；只有前序+后序无法确定树（左右不确定）也去硬解。

题目：扫描线（矩形面积并）
难度：困难
标签：计算几何,扫描线,线段树
描述：平面上若干个边与坐标轴平行的矩形，求它们覆盖区域的总面积。
题解思路：扫描线：把每个矩形拆成"下边进入（+1）"与"上边离开（-1）"两个事件，按 y 排序。竖直方向维护当前被覆盖的 x 区间总长度（用线段树区间加与覆盖计数），相邻事件间面积增量 = 覆盖长度 × y 差。x 需离散化。复杂度 O(n log n)。
常见错误：线段树的"覆盖段长度"在标记为 0 时没有正确由子节点合并；离散化边界（开闭区间）处理错；事件 y 相等时的顺序导致算负面积。

题目：SPFA 与最短路算法选型
难度：中等
标签：图论,最短路,选型
描述：面对一道最短路题，如何在 Floyd / 朴素 Dijkstra / 堆优化 Dijkstra / SPFA / Bellman-Ford 中选择合适算法。
题解思路：选型口诀：n≤500 且多源 → Floyd；非负权单源 → 堆 Dijkstra O((V+E)logV)；有负权、判负环、约束经过边数 → Bellman-Ford/SPFA；有负环叠加限制 → 分层图或 Bellman-Ford 按 k 轮。SPFA 平均快但可被卡到 O(VE)，比赛中非负权慎用。
常见错误：无脑 SPFA 被构造数据卡 TLE；分层图思路漏建层次间转移边；忽略题目隐含的"必须恰好 k 条边"约束（Bellman-Ford 第 k 轮的松弛结果）。

描述：如何用 Codeforces（CF）有效训练，以及 Div./Rating 是怎么运作的。

题目：对拍（随机数据验证）方法
难度：中等
标签：竞赛策略,测试,随机化
描述：赛中写不出正解或担心代码出错时，如何用对拍快速验证正确性。
题解思路：对拍三件套：数据生成器 gen.cpp（按数据范围随机，注意小数据更容易暴露错误）、暴力/标程 sol.cpp、待测正解 me.cpp。写批处理或 shell 循环：生成数据 → 分别运行 → diff 比较输出，不一致即停并保存该组数据。n 小（1e5 以内的题可缩到 1e3）时暴力正确率有保障，是 WA 找不到 bug 的最强工具。

题目：比赛读题与样例分析技巧
难度：简单
标签：竞赛策略,读题
描述：拿到一道题后，如何高效读题并避免因读错题面而浪费大量时间。
题解思路：三遍读题法：第一遍通读抓主线（输入输出与求什么）；第二遍逐句抠约束（数据范围、特殊保证、"恰好/至多"措辞），把数字划出来；第三遍手动算样例，对不上就说明理解有误。把约束翻译成复杂度上界：n=1e5 → 需要 O(n log n) 或 O(n)，这直接提示算法方向。英文题面先看 Input/Output 说明再读题干。
常见错误：跳过"Constraints"直接想算法；把"at most"看成"exactly"；手动验样例嫌麻烦；多组数据忘记初始化变量；输出格式（行尾空格、Case #x 前缀）没注意。

题目：刷题分类训练路线（零基础到区域赛）
难度：简单
标签：竞赛策略,训练路线,知识点
描述：从只会语法到能打区域赛，应该按什么顺序训练知识点与难度。

题目：时间复杂度估算与 TLE 排查
难度：简单
标签：竞赛策略,复杂度,性能
描述：拿到题目如何快速估算可用算法的复杂度上界，以及提交 TLE 后如何排查。
题解思路：经验表：n≤10 用 O(n!)；n≤20 用 O(2^n)；n≤500 用 O(n³)；n≤5000 用 O(n²)；n≤1e5 用 O(n log n)；n≥1e6 必须 O(n) 或 O(n log n) 且注意常数。1 秒约 1e8~1e9 次简单运算（取决于 OJ）。TLE 排查顺序：先确认算法量级是否匹配 → 检查是否死循环（while 条件不变量）→ 检查输入输出效率 → 常数优化（减少取模、数组访问局部性）。
常见错误：以为 O(n log n) 的 log 可以忽略（n=1e7 时 log 也有 24 倍）；STL 递归/map 常数大导致卡常；memset 大数组放在多组数据的循环内；没算内存（1e8 个 int = 400MB 必然 MLE）。
