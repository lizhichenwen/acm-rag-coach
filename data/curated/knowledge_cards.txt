题目：网络流最大流（Dinic 算法）
难度：困难
标签：网络流,最大流,Dinic,图论
领域：图论
描述：给定有向图与源点 s、汇点 t，每条边有容量，求从 s 到 t 的最大可行流量。
题解思路：Dinic 的核心是"分层 + 阻塞流"。先用 BFS 按残量网络把点分层，若 t 不可达则结束；再在层号严格递增的边上用 DFS 反复找增广路，一次 DFS 走完当前层次图的全部可行流（当前弧优化避免重复扫边）。复杂度 O(V²E)，二分图匹配等常见模型远低于上界。反向边容量用于反悔。
常见错误：忘记建反向边或反向边容量初值写错；DFS 中不更新当前弧导致退化；层号判断写成"小于等于"而非"等于 +1"。

题目：最小割与最大流的关系
难度：困难
标签：网络流,最小割,图论
领域：图论
描述：把点集划分为含 s 的 S 与含 t 的 T，割的容量为跨边容量之和，求最小割。
题解思路：最大流最小割定理——最大流值等于最小割容量。求完最大流后，在残量网络上从 s 出发能到达的点集就是最小割的 S 侧，跨越 S→T 且已满流的边构成一个最小割方案。很多"最小代价切断某些联系"的题本质就是最小割建模。
常见错误：只会套最大流模板但不会建模（把点权拆点、把收益取反）；把"最小点割"直接当边割做，忘记拆点。

题目：强连通分量（Tarjan）
难度：困难
标签：图论,强连通分量,Tarjan
领域：图论
描述：有向图中若两点互相可达则属同一强连通分量，求所有强连通分量并缩点。
题解思路：一次 DFS 维护 dfn（首次访问时间）与 low（能回溯到的最小 dfn），用栈保存当前路径上的点。当 dfn[u]==low[u] 时，栈中 u 及其之上的点构成一个强连通分量。缩点后原图变成 DAG，可在 DAG 上做拓扑 DP 求最长路、计数等问题。
常见错误：low 更新时把"已在栈中"的判定漏掉，导致跨分量的边污染 low；缩点后重边未去导致入度统计错误。

题目：2-SAT 问题
难度：困难
标签：2-SAT,强连通分量,图论
领域：图论
描述：n 个布尔变量，若干形如 (a 为真 或 b 为真) 的约束，判断是否存在赋值方案并给出一组解。
题解思路：把每个变量拆成 x 与 ¬x 两个点，约束 (a∨b) 等价于 (¬a→b) 与 (¬b→a) 两条有向边，建图后求强连通分量。若 x 与 ¬x 在同一分量则无解；否则把分量按拓扑序反向取值（Tarjan 求出的分量编号自带逆拓扑序，可直接用编号比较）得到一组可行解。复杂度 O(n+m)。
常见错误：拆点编号写错（x 与 ¬x 混用）；取值方向搞反；只判可行性忘记输出方案。

题目：后缀数组（SA）
难度：困难
标签：字符串,后缀数组,倍增
领域：字符串
描述：把字符串的所有后缀按字典序排序，得到排名数组 sa 与相邻后缀的最长公共前缀数组 height。
题解思路：倍增法。先按长度为 1 的字符排名，再每次把"前一半排名 + 后一半排名"作为二元组重新排序（基数排序做到 O(n) 每轮），共 O(log n) 轮。height 数组利用性质 height[rank[i]] ≥ height[rank[i-1]] − 1 线性求出。可解决多模式串匹配、本质不同子串计数、最长重复子串等问题。
常见错误：基数排序的计数数组未清空；height 递推时未处理 i=0；sa 下标从 0 还是 1 开始不统一。

题目：FFT/NTT 多项式乘法
难度：困难
标签：数学,FFT,NTT,多项式
领域：数学
描述：给定两个多项式，求其乘积的系数，次数可达 1e5 量级。
题解思路：系数表示下乘法是 O(n²) 卷积；用单位根做点值变换后，卷积变成逐点相乘，再逆变换回系数，复杂度 O(n log n)。FFT 用复数单位根，存在精度误差；NTT 在模 998244353 等 NTT 友好模数下用原根代替单位根，全程整数运算无误差。实现要点是蝴蝶变换（位逆序重排）与长度补到 2 的幂。
常见错误：长度未补到 2 的幂；逆变换忘记除以 n；NTT 模数原根取错（998244353 的原根是 3）。

题目：博弈论与 SG 函数
难度：困难
标签：数学,博弈论,SG函数
领域：数学
描述：两人轮流操作，无法操作者输（正常博弈），判断先手是否必胜。
题解思路：先找必败态（无合法操作）。单个游戏局面的 SG 值 = 其所有后继局面 SG 值集合的 mex；多个互不干扰的子游戏整体 SG 值等于各子游戏 SG 值的异或和，非零则先手必胜。SG 值常能通过打表找规律（周期、奇偶性），避免状态爆炸。
常见错误：混淆"不能操作者输"与"不能操作者赢"两种规则；多堆博弈忘记异或而是求和；打表范围不够导致规律误判。

题目：概率与期望 DP
难度：困难
标签：动态规划,概率,期望
领域：动态规划
描述：在随机过程中求达到目标状态的期望步数或某事件的概率。
题解思路：期望具有线性性，可对状态设 E[i] 表示从状态 i 出发到终止的期望代价，列出 E[i] = 1 + Σ p(i→j)·E[j] 的方程。若转移有环（如随机游走），需要高斯消元或利用特殊结构（如一元递推、树上从根到叶两遍扫描）求解；概率题则直接做前向递推，注意"至少/恰好"的区分。
常见错误：把期望当概率直接相加；有环时直接记忆化搜索导致死循环；忘记除以概率分母。

题目：折半搜索（Meet in the Middle）
难度：困难
标签：算法思想,折半搜索,枚举
领域：算法思想
描述：n 个物品各选或不选，求满足某约束的方案数，n 约 40，无法直接 2^n 枚举。
题解思路：把 n 个物品分成两半，分别枚举 2^(n/2) 种状态并记录（如总和、选中个数），把其中一半排序或建哈希表；再枚举另一半，在表中二分/查表统计能配对的状态数。复杂度从 O(2^n) 降到 O(2^(n/2)·log 2^(n/2))。适用于子集和、方程解的个数、最大异或等。
常见错误：两半拆分不均匀导致常数失衡；配对时的边界（等于/小于等于）判错；重复计数未去重。

题目：交互题的解题范式
难度：困难
标签：竞赛技巧,交互题
领域：竞赛技巧
描述：题目不直接给出输入，程序需要通过标准输入输出与评测机反复询问来获取信息，询问次数有上限。
题解思路：先判断信息获取的"每次询问能排除多少可能"，据此选范式：①二分型——询问把候选区间对半切，O(log n) 次；②随机化型——随机取样估计比例，用于无法精确二分的场景；③增量构造型——每次询问确定一个元素，逐步构造答案。实现上必须每次询问后刷新输出缓冲，且严格遵守次数上限。
常见错误：输出后未 flush 导致交互死锁；询问次数超限；把交互题的"回答"当成一次性输入读入全部。

题目：构造算法常见套路
难度：困难
标签：算法思想,构造
领域：算法思想
描述：题目要求给出一个满足条件的方案（排列、图、矩阵、操作序列），而不是求最优值。
题解思路：三类常用套路：①奇偶性/不变量分析——先判断何时无解，再按奇偶分情况构造；②归纳构造——先构造 n=1,2 的答案，再说明如何从规模 k 扩展到 k+1；③图构造——把条件翻译成度数序列或连通性，用贪心连边满足约束。构造题的关键是"先证后构"，边写边验证不变量。
常见错误：只构造出样例的情况；没有证明无解条件导致输出错误方案；下标与 1-based/0-based 混用。

题目：树链剖分
难度：困难
标签：数据结构,树链剖分,线段树
领域：数据结构
描述：在树上支持路径修改/查询与子树修改/查询，操作数可达 1e5。
题解思路：通过两次 DFS 求出重儿子、子树大小、深度、父节点与 dfs 序，把树拆成若干条重链；同一条链上的点在 dfs 序中连续，因此路径查询可拆成 O(log n) 段连续区间，交给线段树维护。子树在 dfs 序中同样是连续区间，天然支持子树操作。总复杂度 O(n log² n)。
常见错误：两次 DFS 的递归顺序写错（第二次 DFS 必须先走重儿子）；区间映射时 top 与 dfn 混用；递归深度过大导致爆栈。

题目：最近公共祖先（LCA 倍增）
难度：困难
标签：数据结构,树,LCA,倍增
领域：数据结构
描述：多次询问树上两点的最近公共祖先。
题解思路：预处理 up[k][u] 表示 u 向上跳 2^k 步到达的节点，depth 表示深度。询问时先把较深的点跳到与另一点同深度，再从大到小同时上跳，直到两点的父节点相同，该父节点即 LCA。预处理 O(n log n)，单次询问 O(log n)。也可用欧拉序 + RMQ 或 Tarjan 离线。
常见错误：深度差跳完后忘记判"已相等"直接返回父节点；up 数组第二维开小；根节点父节点未指向自己导致越界。

题目：树状数组
难度：中等
标签：数据结构,树状数组
领域：数据结构
描述：支持单点修改与前缀和查询，操作数 1e5。
题解思路：利用 lowbit 把下标拆成二进制区间，tree[i] 维护区间 (i−lowbit(i), i] 的和。修改时 i += lowbit(i) 向上更新，查询时 i −= lowbit(i) 向下累加，均为 O(log n)。配合差分可支持区间修改 + 单点查询；配合"维护两个树状数组"可支持区间修改 + 区间查询。
常见错误：lowbit 写成 i&(i-1)（那是去掉最低位，不是取最低位）；下标从 0 开始导致死循环；区间查询忘记做前缀和相减。

题目：单调队列优化 DP
难度：困难
标签：动态规划,单调队列,优化
领域：动态规划
描述：转移形如 dp[i] = min/max{ dp[j] + cost(i,j) }，且 j 的可行区间随 i 单调滑动。
题解思路：若可行决策区间是滑动窗口且代价可分离，用双端队列维护"候选下标"，保持队列内 dp 值的单调性：每次插入新决策前从队尾弹出比它差的，取最优时从队首弹出已过期的。这样每个下标进出队各一次，把 O(n²) 降到 O(n)。常见于"划分型 DP""滑动窗口最值""多重背包"。
常见错误：过期判断用值而不是下标；队尾弹出条件写成严格大于/小于导致相等元素被误删；窗口边界与 i 的偏移量算错。

题目：状态压缩 DP
难度：困难
标签：动态规划,状压DP,位运算
领域：动态规划
描述：状态由若干元素的"选/不选"构成，元素个数 n 通常不超过 20。
题解思路：用一个整数的二进制位表示集合，dp[mask] 表示该集合下的最优值，转移时枚举"加入哪个未选元素"或"枚举子集"。常用技巧：预处理合法状态（相邻位不同时为 1）、用 lowbit 枚举子集、滚动数组压维。复杂度 O(2^n · n)。
常见错误：枚举子集写成 for(sub=mask; sub; sub=(sub-1)&mask) 时漏掉 0；n 超过 22 仍用状压导致超时超存；位运算优先级不加括号。

题目：数位 DP
难度：困难
标签：动态规划,数位DP
领域：动态规划
描述：统计区间 [L,R] 内满足某种数位性质的数的个数，如不含连续相同数字、数位和整除 k。
题解思路：把答案写成 f(R) − f(L−1)，对上限做"逐位确定"的 DFS：参数通常为（当前位、是否贴着上界、前一位数字、已累计量）。记忆化时只能缓存"未贴上限"的状态（贴上界的状态依赖具体输入，不能复用）。这是数位 DP 的核心实现纪律。
常见错误：把 limit=true 的状态也记忆化导致答案错误；前导零处理不当（影响"是否含某数字"类统计）；L−1 为负数时未特判。

题目：莫队算法
难度：困难
标签：数据结构,莫队,分块
领域：数据结构
描述：多次区间询问且可离线，要求在 O((n+q)√n) 内回答（如区间不同数个数）。
题解思路：把所有询问按左端点所在块排序、块内按右端点排序（奇偶优化让右指针往返减少一半），然后维护当前区间 [L,R] 与答案，通过不断移动左右指针"增量式"加入/删除元素。关键是单次加入/删除必须是 O(1) 可维护的。带修莫队再加一维时间戳，块大小取 n^(2/3)。
常见错误：块大小取 √n 却在带修场景下不调整；指针移动顺序导致区间非法（L>R）；删除操作未考虑元素计数归零。

题目：分块
难度：中等
标签：数据结构,分块,暴力
领域：数据结构
描述：维护长度为 n 的序列，支持区间加、区间求和（或区间查询某值排名），n,q 约 1e5。
题解思路：把序列切成 √n 块，每块维护总和与懒标记。整块操作打标记 O(1)，零散元素暴力处理 O(√n)，单次操作 O(√n)，总复杂度 O(q√n)。比线段树好写、比分块树好调，适合"想不清楚怎么合并"的题。
常见错误：懒标记只在整块生效却在零散操作时忘记下推；块大小与块数计算不一致导致越界；边界块重复计算。

题目：欧拉函数与中国剩余定理
难度：困难
标签：数学,数论,CRT,欧拉函数
领域：数学
描述：求 1..n 中与 n 互质的数的个数；以及求解模数两两互质（或一般）的同余方程组。
题解思路：欧拉函数 φ(n) = n·Π(1−1/p)，对 n 试除质因子即可在 O(√n) 内求出，筛法可 O(n) 预处理。CRT 用"逐步合并"：已知前 k−1 个方程的解 x 与模数 M，加入第 k 个方程时解形如 x + t·M，代入解出 t，合并后模数为 lcm。模数不互质时需用 exgcd 判是否有解（gcd 必须整除差值）。
常见错误：CRT 合并时未对模数取模导致溢出；模数不互质仍套互质版公式；欧拉函数试除时漏掉最后剩余的质因子。
